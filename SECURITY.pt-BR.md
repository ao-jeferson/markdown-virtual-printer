# Política de segurança

[Read in English](SECURITY.md)

Este projeto está em fase inicial de protótipo. Não processe documentos sensíveis com builds de origem desconhecida. A conversão deve ocorrer localmente; trabalhos de impressão não devem ser enviados a serviços de terceiros.

Reporte vulnerabilidades em privado ao mantenedor pelos canais do GitHub. Não publique documentos privados, dados pessoais nem detalhes de exploração em Issues públicas.
