# Código de conduta

Esperamos comunicação respeitosa, inclusiva e focada no trabalho. Assédio, ataques pessoais, discriminação e exposição de dados privados não são aceitos. Mantenedores podem editar ou remover conteúdo que viole estas regras e restringir participação em caso de abuso. Para relatar um problema, contate os mantenedores em privado pelos canais disponíveis no GitHub.
