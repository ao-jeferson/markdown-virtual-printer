# Markdown Virtual Printer v0.1.1

Experimental cross-platform installer preview. Printer registration and end-to-end print flows still need validation on supported operating systems.

## Packages

- Linux: Debian package and compressed runtime bundle.
- macOS: unsigned, unnotarized package and runtime bundle. The current installer cannot register its CUPS backend on SIP-protected macOS; do not treat it as a functional printer installation.
- Windows: MSIX and installation files signed with a temporary self-signed development certificate. Review the included certificate before installing.
- Android: debug-signed APK for ARM64 and x86_64. Device installation and print/save flow have not yet been validated.

## Known limitations

- macOS printer queue registration requires a supported integration that does not write to SIP-protected CUPS directories.
- Windows package registration and print workflow remain experimental and need host validation.
- Linux installation and save flow need validation on a clean host.
- Android requires device-level verification.

# Markdown Virtual Printer v0.1.1 (Português)

Prévia experimental de instaladores multiplataforma. O registro da impressora e os fluxos completos de impressão ainda precisam ser validados nos sistemas compatíveis.

## Pacotes

- Linux: pacote Debian e arquivo compactado do runtime.
- macOS: pacote sem assinatura e sem notarização. O instalador atual não consegue registrar o backend CUPS no macOS protegido por SIP; não considere essa instalação uma impressora funcional.
- Windows: MSIX e arquivos de instalação assinados com certificado temporário autoassinado de desenvolvimento. Confira o certificado incluído antes de instalar.
- Android: APK assinado para depuração, para ARM64 e x86_64. A instalação em dispositivo e o fluxo de impressão/salvamento ainda não foram validados.

## Limitações conhecidas

- O registro da fila no macOS depende de uma integração compatível que não grave em diretórios CUPS protegidos pelo SIP.
- O registro do pacote e o fluxo de impressão no Windows são experimentais e precisam ser validados no sistema.
- A instalação e o salvamento no Linux precisam ser validados em um host limpo.
- Android precisa de verificação em dispositivo.
