# Como contribuir

Ideias e pull requests são bem-vindos. A prioridade atual é uma impressora virtual nativa confiável que salve trabalhos de impressão como Markdown.

[Read in English](CONTRIBUTING.md)

## Envie uma ideia

1. Abra uma Issue com o modelo **Idea** ou **Ideia**, em inglês ou português.
2. Adicione as labels em inglês type: idea e status: proposed. Quando souber, adicione uma label de plataforma e uma de área.
3. Os mantenedores discutem o escopo e decidem se a ideia entra no roadmap. Uma ideia proposta não é promessa nem tem data definida.

## Envie código

1. Faça fork do repositório público.
2. Para trabalho normal, crie uma branch feature, fix, docs ou chore a partir de develop.
3. Abra um pull request para develop. Para correção urgente em produção, use hotfix/<assunto> a partir de main e direcione o PR para main.
4. Aguarde a revisão e atenda os pedidos antes do merge.

Consulte a [estratégia Gitflow](docs/branch-strategy.pt-BR.md) e o [roadmap](ROADMAP.pt-BR.md).

## Orientações para pull requests

- Mantenha cada PR focado e explique o efeito para o usuário.
- Mantenha a conversão de documentos local; não envie trabalhos de impressão a serviços externos.
- Atualize a documentação em inglês e sua tradução em português quando o comportamento ou as plataformas suportadas mudarem.
- Inclua exemplos pequenos e anonimizados ao adicionar um formato.
- Nunca inclua documentos privados, dados pessoais, credenciais ou arquivos de usuários.

## Relatos

Informe o sistema operacional, a versão, o formato de entrada e um exemplo mínimo anonimizado. Não anexe documentos confidenciais a Issues públicas.

## Licença

Ao enviar intencionalmente uma contribuição para inclusão, você concorda que ela possa ser distribuída sob a licença MIT deste repositório.
