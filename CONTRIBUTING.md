# Contributing

Contributions are welcome through pull requests. Open an Issue first for substantial changes so scope can be discussed.

- Keep changes focused on the native virtual printer and shared Rust core.
- Follow the platform order in the roadmap unless an Issue explains a dependency.
- Document user-visible behavior in English and Brazilian Portuguese when practical.
- Do not include private conversations or brainstorming notes in the repository.
- Describe behavior, affected platform, and verification in pull requests.

See [docs/BRANCHING.md](docs/BRANCHING.md) for branch and release flow.
