# Roadmap

GitHub Issues and the public project board track individual work items.

## In progress

- Define the shared Rust document model and Markdown output contract.
- Establish native virtual printer integration for macOS.

## Planned

- macOS print pipeline, save flow, and installer.
- Windows virtual printer integration and installer.
- Linux CUPS integration and installer.
- Preserve document structure where the OS print job provides it.
- Evaluate OCR for image-based and scanned print jobs.
- Add report formatting options for chat output.

## Later

- Android and iOS support, without a target date.
